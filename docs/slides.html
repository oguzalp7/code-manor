Model testten geçemeyince kodunu düzeltmek yerine tests/ dosyasındaki expect(...) assertion satırlarını gizlice siler veya gevşetir.

Acceptance Criteria (AC-01..n)
03

Test-Driven Dev (TDD)

Asla spekülatif ("belki lazım olur") kod yazılmaz. Önce başarısız olan kırmızı test yazılır, ardından sadece testi geçirecek en az (frugal) kod üretilir ve refactor edilir.

Red ➔ Green ➔ Refactor

BİLETLENME MİMARİSİ

Ask-Matt: Sis'ten Biletleme Grafına (DAG)

1 ZİHİNSEL SİS (FOG)

2 ŞARTNAME (SPEC)

3 DİKEY BİLETLER
/to-tickets

4 YÜRÜTME & İZLEME
/implement (TDD)

Maid biletteki kriterler için önce kırmızı testi yazar, yeşile çevirir ve no-mistakes kapısından geçer.

1. Zero-Orphan Kuralı:

Şartnamedeki hiçbir [AC-xx] kriteri açıkta kalamaz. Tüm kriterler biletlere %100 dağıtılmalıdır.

2. Blocking Edges (DAG):

Her bilet yalnızca kendisini doğrudan engelleyen biletleri bekler. Bloke iş bittiğinde sonraki bilet otomatik olarak tasks-axi ready durumuna geçer.

frontier-axi Upstream Fog

Zihinsel Sis Yönetimi

Pişmemiş fikirler, mimari kararlar ve açık sorular .frontier.toml dosyasında tutulur. Belirsiz işlerin görev kuyruğuna sızmasını engeller.

tasks-axi Downstream Vertical

Deterministik Görevler

Yalnızca şartnamesi ve kabul kriterleri (AC) netleşmiş dikey işler .tasks.toml kuyruğuna girer. Ajanların keyfi TODO üretmesini engeller.

$ tasks-axi ready
$ tasks-axi done <id>
no-mistakes Verification Gate

Tavizsiz Bekçi

Commit ve PR öncesi test tampering denetimi, linter, tip kontrolü ve test koşumu yapar. Sıfır hatayla çıkış (exit 0) zorunludur.

$ no-mistakes axi run --skip ci
🐙 GitHub Tercihi: Ekstra wrapper yerine doğrudan resmi GitHub CLI (gh) kullanıyoruz.
gh pr checks --watch
TAVİZSİZ DOĞRULAMA

"no-mistakes" Nedir ve Ne Yapar?

Ajanın "Halledildi patron!" demesine değil, deterministik kanıtlara güvenin.

🛡️

Anti-Tampering Denetimi

Test ve spesifikasyon dosyalarındaki yetkisiz satır silmelerini, gevşetilen assertion'ları tespit eder. Ajanın testi manipüle etmesini engeller.

🔍

Katı Tip & Lint Kapısı

Projenin TypeScript, Rust veya Python derleyicisini çalıştırır. any kaçamaklarını veya atlanmış tip hatalarını anında yakalar.

⚡

Tier 1: Mandatory Local Gate

Her bilet bitiminde make check (lint + types + tests) komutunun temiz bir exit 0 verdiğini zorunlu kılar.

🔒

Diff & Invariant Güvenliği

Kapsam dışı dosya değişikliklerini, gizli anahtarları veya yetkisiz mimari kaymaları analiz eder; risk yüksekse birleşmeyi (merge) engeller.
